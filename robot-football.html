QC-iLoboke Robot Football Strategy v5.2

A referee-aware Lua strategy layer for coordinating a three-robot football team in the SOM environment.

TASK CONTEXT

Coordinate attack, defence and set plays under match-state constraints.

The official platform description frames QC-iLoboke as a small football-robot system combining image processing, autonomous decision-making, path planning, obstacle avoidance and C++/Lua programming. A published RoboCom task description for the same SOM 3.4.2 environment required two attacking robots to complete a pass before shooting against a fixed goalkeeper across five field positions, with each sequence completed within 15 seconds. The repository is presented as strategy evidence for that platform family, not as a claim that every season used identical rules.

SYSTEM
  1. Routes referee messages into normal play, kick-off, penalties, ball placement, stop, halt and game-over handlers.
  2. Assigns fixed Goalie, Kicker and Receiver roles through blue/yellow team configuration.
  3. Uses finite-state plays to acquire the ball, move into receiving positions, exchange passes and transition into shooting.
  4. Separates reusable role-to-skill bindings from match-level tactical sequences and opponent profiles.
PUBLIC RELEASE

Reviewable strategy code without proprietary runtime binaries.

The v5.2 repository contains 196 parse-validated Lua files plus team, robot and kick configuration. Executables, compiled DLL skills, Qt and Visual C++ runtimes, logs, captured vision data and encrypted submission archives were removed. The repository includes a source manifest and a validator for Lua, JSON, XML, file hashes and the source-only boundary.

LIMITATIONS

The supplied SOM attachment did not contain native C++ skill source or a standalone competition photograph. The public repository therefore supports strategy review but cannot reproduce a full match without the original SOM/PlayBot host and compiled motion skills.
